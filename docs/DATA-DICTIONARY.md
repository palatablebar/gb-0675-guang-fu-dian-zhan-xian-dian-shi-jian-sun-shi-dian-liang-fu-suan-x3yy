# 功率与限电定义

设备额定功率为kW。遥测kW与MW统一为kW，辐照度为W/m²。样本时刻须带偏移，统一UTC。记录代表自采样时刻起600秒的左值保持区间，超过600秒不外推，缺测保持未定。
每台设备重叠或相邻限电事件先求并集，再按遥测及有效期边界切分半开区间。样例INV-A的10:00–10:20及10:10–10:30合并为30分钟，不能重复积分重叠10分钟。
基线只采用同区域、同采样时刻、同100W/m²辐照档、健康且不处于限电中的参考逆变器；至少2台。对参考功率按各自额定功率归一，取中位数再乘目标额定功率，基线不超过目标额定功率。无合格对照返回NO_REFERENCE及null损失，不填0。
每片段损失=max(基线−实际,0)×秒数/3600。实际高于基线时损失0。计算保留Decimal精度，汇总后统一保留0.0001kWh；未定时长单独展示，不并入已确定损失。
清批INV-A基线100kW、实际60kW、并集30分钟，损失20kWh；INV-B基线50、实际30、20分钟，损失6.6667kWh。总确定损失26.6667kWh。能量核验按实际+非负损失计算可解释基准电量。
同设备同一时刻不同观测全部隔离；同值重复观测保留稳定编号。封存需无隔离和未定片段。此工具供离线复算，不包含生产控制或电网调度。

## 列别名与功率单位裁定（映射版本治理）

供应商把功率拆成“功率/计量单位”两列，且同场站新旧文件混用 kW、MW 与中文列名。裁定由版本化注册表 `app/mapping.py` 声明，版本不可变、只允许追加：

- **兼容（采信并留痕）**：表头命中已登记字段别名，解析到唯一规范字段；单位命中已登记单位别名（kW/kW/千瓦 系数1，MW/mw/兆瓦 系数1000），按系数换算为 kW。每条规范记录保留血缘：原列名（`header_map`）、原始功率值 `power_raw`、原始单位 `unit_raw`、规范单位、换算系数 `unit_factor`、换算依据 `conversion_basis`。
- **待查（整行/整值隔离，不进基线与损失）**：列名语义未证实（如“发电量/电量”，可能是 kWh 而非 kW）记 `FIELD_PENDING`；单位语义未证实（W/瓦，量级与逆变器不符）记 `UNIT_PENDING`；单位完全未登记记 `BAD_UNIT`；未登记列名记 `UNKNOWN_COLUMN`。任何情况下不得静默猜解或除以 1000。
- **同设备同一时刻唯一性**：在换算为 kW 后比较。数值等价的跨单位重复（如 60千瓦 与 0.06兆瓦）只保留稳定编号较小的一条，另一条记 `SAMPLE_DUPLICATE` 并标注 `duplicate_of`；换算后仍不同的两条全部记 `SAMPLE_CONFLICT` 隔离。保证同一设备同一时刻最多一条观测。
- **版本与复核**：批号 digest 纳入规则版本与映射版本，不同映射版本产生不同批号；映射版本更新后旧批结果原样保留、不被覆盖，已复核批（状态“已复核”）重复提交返回 409 `BATCH_REVIEWED`。切换映射版本若与原输入不兼容（如旧版不识别中文列名）返回 409 `MAPPING_INCOMPATIBLE` 并保留旧版结果（`fallback_run_id`）。
- 页面在采信页展示逐列映射来源与裁定码，在设备页展示单位换算结果、系数、依据与待查行；归档 `evidence.json` 含 `mapping_version` 与 `header_audit`。
